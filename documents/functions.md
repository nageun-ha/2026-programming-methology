# 기능 정의서

> 현재 팀에서 합의된 내용을 정리한 문서입니다. 논의가 진행되면 계속 업데이트합니다.

## 1. 자세 판단 기능

일정한 주기로 사용자가 제시된 자세를 수행했는지 판단한다.

- **화면 구성**: 화면을 절반으로 나누어 사용
  - 한쪽: 사용자의 관절(포즈)을 실시간으로 표시
  - 다른 한쪽: 따라 해야 할 동작(자세) 제시
- **자세 제시**: 체보(빤짝이)
- **판단 주기**: 일정한 주기로 자세 수행 여부를 판단

## 2. 리워드 시스템

성취감을 높여 운동을 지속할 동기를 제공한다.

- **방식**: 잔디
- **목적**: 꾸준한 운동 습관 형성

## 3. 추후 논의 필요

- [ ] 자세 판단 주기 (몇 초/몇 분 간격인지)
- [ ] 자세 수행 성공 기준 (관절 각도 허용 오차 등)
- [ ] 제시할 자세의 종류와 개수
- [ ] 잔디 적립 조건 (하루 몇 회 성공 시 적립되는지)
- [ ] 사용할 포즈 인식 라이브러리/모델
